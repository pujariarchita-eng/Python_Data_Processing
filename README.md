# Python Data Processing

## Project Description

This project demonstrates basic data processing using Python. 
A collection of structured student records is created using lists 
and dictionaries, and useful summary statistics are generated 
from the data.

## Objective

The objective of this project is to understand and implement 
basic data processing concepts using Python.

## Technologies Used

- Python
- Jupyter Notebook

## Concepts Used

- Lists
- Dictionaries
- Loops
- Conditional Statements
- Functions
- List Comprehension
- Data Filtering
- Basic Statistics

## Dataset

The project uses student records containing:

- Name
- Marks
- Age
- Department

## Features

The program performs the following operations:

1. Creates structured student records.
2. Displays student information.
3. Calculates the total number of students.
4. Calculates average marks.
5. Finds the highest marks.
6. Finds the lowest marks.
7. Calculates average age.
8. Filters students who scored 80 or above.
9. Classifies students as Pass or Fail.
10. Counts students by department.
11. Displays examples of processed records.

## Summary Statistics

The program generates statistics such as:

- Total Students
- Average Marks
- Highest Marks
- Lowest Marks
- Average Age
- Number of Pass Students
- Number of Fail Students
